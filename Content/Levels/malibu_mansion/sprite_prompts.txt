MALIBU MANSION — LLM SPRITE PROMPTS
================================================================================
Case: "The Missing Parrot" (Rudebeak). Cozy Studio Ghibli detective aesthetic.

HOW TO USE
- CHARACTERS: one prompt each, portrait dimensions, single full-body figure.
- OBJECTS: batched into 5x2 grid sheets (10 objects per prompt) to save runs.
  Generate the sheet, then crop each cell out using the numbered legend.
- Per-name sprites live under each room's "Interactables/" folder and must be
  named after the interactable id (e.g. Interactables/inspect_maid.png).
  If the file is missing, the game falls back to the placeholder in room_config.
- Every prompt requests a plain solid white background for easy cutout.
